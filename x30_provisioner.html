It works in Chrome or Edge on Android and Windows, and needs the page served over HTTPS or from localhost. On iPhone use the Bluefy browser. If you opened this from an http:// address on the LAN, allow that address in chrome://flags/#unsafely-treat-insecure-origin-as-secure.

1 · Connect

Excite the tag first: hold the rear button until it flashes blue. Then pick it from the browser's device list. Connecting reads every block and stores a snapshot before anything is written.

Link settings

Characteristic: 51f1f198-4321-9abc-4321-0067eaa0da40. If a future firmware moves it, dump_x30_services.py on the PC prints the new service UUID.

2 · Config

FieldOn tagTargetApply

Editing a target ticks Apply. Only ticked fields are sent, and only if they differ from the tag. Scan fields are write-only: the firmware never reports them back.

3 · Write

Sends set* for ticked fields, stops before savecfg on the first rejection so the tag reverts on disconnect, then savecfg, then reconnects and reads every field back. res 0 alone is not trusted.
